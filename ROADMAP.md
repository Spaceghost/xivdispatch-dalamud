# XivDispatch roadmap

Published previews are design demonstrations. Check a milestone only after its acceptance evidence exists.

- [x] Fictional workspace and persistent-draft preview
- [ ] Official Slack window hosting feasibility
- [ ] Workspace-authorized OAuth and identity checks
- [ ] DMs, pinned channels and thread reads
- [ ] Event delivery and rate-limit-aware history
- [ ] Explicit replies and reactions
- [ ] Quiet-session rules and optional Prism panels
- [ ] Live-account acceptance before any installer release

The feature vote informs priorities; it is not a shipping promise.
